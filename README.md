# SKY HOP!

HTML 1ファイル（[index.html](index.html)）だけで動作する、ポップな雰囲気の**縦スクロール・アスレチックゲーム**です。

---

## 1. ゲームの概要

**SKY HOP!** は、下から迫ってくるポップな波に落ちないように足場を登り続け、**生き残るほどスコアが伸びていく**サバイバル型アスレチックアクションです。

- **外部ファイル・ライブラリ不要**: Canvas 2D と Web Audio API を用いて、[index.html](index.html) 1ページのみで描画・効果音・セーブ機能（`localStorage`）が完結しています。
- **スコアに応じた難易度上昇**: スコアと到達レベルに応じてスクロールが速くなり、動く足場（LV.2〜）・崩れる足場（LV.3〜）・トゲぷに障害物（LV.4〜）が段階的に登場します。背景の空も朝空 → 夕焼け → トワイライト → 宇宙へと変化します。
- **3レベルごとのボス戦**: `LV.3 → 4`、`LV.6 → 7`、`LV.9 → 10` …の節目でボスが出現し、**ボスを倒さないと次のレベルへ進めません**。道中で `⚔️ パワー星` を集めて攻撃力（`ATK`）を上げ、スター弾と踏みつけでボスを討伐します。
- **スコア通貨＆パッシブスキル**: プレイで獲得したスコアはそのまま通貨（`pt`）として所持でき、`SKILL SHOP` で初期残機や初期攻撃力などの永続パッシブスキルを購入できます。

---

## 2. 遊び方（操作方法）

ブラウザで [index.html](index.html) を開くだけですぐに遊べます。

### キーボード操作
| キー | 操作 |
| :--- | :--- |
| `←` `→` / `A` `D` | 左右移動（**画面の左右端で反対側へワープ**） |
| `Space` / `↑` / `W` | ジャンプ（空中で追加1回可能な **2段ジャンプ**／長押しで高さ調整） |
| `P` / `Esc` | ポーズ／再開（ショップ画面では `Esc` で閉じる） |
| `M` | サウンドのミュート切替 |

※ タッチ端末など粗いポインター環境では、画面下部にタッチ操作用ボタンが表示されます。

### 出現アイテム
| アイテム | 効果 |
| :--- | :--- |
| ⚔️ **パワー星** | `ATK` が +1 上昇（ボス戦の火力アップ） |
| 💖 **ハート** | 残機 +1（上限5。落下時は残機を1消費して大ジャンプで自動レスキュー） |
| 🫧 **シャボン玉バリア** | 障害物・ボス攻撃・落下を1回だけガード |
| 🚀 **ブースト** | 一定時間（2.6秒）無敵状態で上昇（お邪魔キャラ撃破・ボスへの接触ダメージ） |
| ⏱️ **スロー時計** | 一定時間（6.0秒）スクロールや敵・動く足場の速度をスロー化 |

### ボス戦とスキルショップ
- **ボスへの攻撃**: ボス戦中は上方向へ **スター弾（威力 = `ATK`）** が自動発射されるほか、ボスの頭上を踏みつけると **クリティカルダメージ（`ATK × 2.5` 切り上げ）** を与えて大きく跳ね上がれます。ボスの急降下攻撃後のスタン中が踏みつけのチャンスです。
- **スキルショップ（`SKILL SHOP`）**: タイトル画面・ゲームオーバー画面から開けます。獲得した `pt` を使って、初期ATK強化（`パワーの紋章`）、初期残機強化（`タフネスハート`）、移動・ジャンプ強化（`スカイブーツ`）、スコア倍率強化（`スコアマスター`）、アイテム出現短縮（`ラッキードロップ`）、開始時バリア（`スタートバリア`）を習得できます。

## 3. 工夫した点

1. **ストレスのない操作感の作り込み**
   - 2段ジャンプに加えて、足場から離れた直後でもジャンプを受け付ける**コヨーテタイム（0.11秒）**、着地直前の入力を取りこぼさない**先行入力バッファ（0.11秒）**、ボタンを離したタイミングによる可変ジャンプ高度を実装し、アスレチックとしての手触りを整えています。
   - 画面左右端のワープ時にキャラクターが一瞬消えて見えないよう、端付近では反対側にも描画を行うシームレス描画を採用しています。
2. **HTML 1ファイル完結のビジュアル＆オーディオ**
   - 外部画像や音声素材を一切使わず、Canvas 2D の図形描画（ぷにっと伸縮するアニメーション、残光パーティクル、ポップテキスト）と Web Audio API によるシンセ効果音のみでポップな演出を完結させています。
   - `localStorage` へのアクセスを `safeGetStorage` / `safeSetStorage` でラップし、環境によってストレージが制限されていてもエラーで停止しないようにしています。
3. **ボス戦の足場保証とレベル進行の整合性**
   - ボス戦突入時は強制スクロールを止め、`ensureArenaPlatforms()` で画面内4段の足場を常に補給することで、戦闘中に足場がなくなって詰むのを防いでいます。
   - 通常のスコア（`score`）とは別にレベル進行用の `climbScore` を管理し、ボス戦が長引いても討伐後にレベルが一気に飛び越えない（次のボスゲートをスキップしない）設計にしています。

## 4. 作りながら変えた点

Git のコミット履歴上は、全機能をまとめた初回コミット（`70364cf`: `Add SKY HOP! vertical athletic game with boss battles and skill shop`、`index.html` 3,497行追加）として記録されています。実装プロセスの中では、テストプレイのフィードバックを受けて以下のように設計を発展・修正しました。

1. **「生き残りスコア型」から「通貨＋永続成長ループ」への拡張**
   - 最初は1プレイ限りのハイスコア更新を目指すシンプルな構成でしたが、プレイを重ねるモチベーションを高めるため、獲得スコアをそのまま通貨（`pt`）として蓄積し、6種類のパッシブスキルを購入できる `SKILL SHOP` を追加しました。
   - ショップ画面を開いている最中に `Space` キーで意図せずゲームが開始・リトライされないよう、`state.shopOpen` による入力ガードと、ボタンクリック後の `.blur()` 処理を入れています。
2. **3レベルごとのボス戦ゲートと `ATK` ステータスの導入**
   - 一定のテンポで山場を作るため、レベルが3上がる節目（`LV.3`、`LV.6`、`LV.9`…）でボス戦を発生させ、討伐するまで次のレベルへ進めない仕組みに変更しました。
   - ボス戦に向けて成長を実感できるよう、新たに攻撃力ステータス（`ATK`）と `⚔️ パワー星` アイテム、自動スター弾・踏みつけクリティカルの仕組みを追加し、ボスを倒すほど次のボスのHP（`18 → 44 → 80 → 132…`）と攻撃パターンが強化されるよう調整しました。
3. **ボス戦中の既存アイテム・ギミックの挙動調整**
   - `🚀 ブースト` をボス戦中に取得した際、カメラ固定中の画面外へ飛び抜けてしまわないよう、アリーナ上部でホバリングしつつボスへ連打ダメージを与えられる挙動へと調整しました。
   - ボス戦中でもアイテムが同じ足場に重なって出現しないよう、未取得アイテムが乗っていない足場を選んで配置するフィルタリングを加えています。
